## How to read this card

- Every value is read from a JSON artifact the gate produced in the run that
  checked this card. Nothing here is hand-copied.
- **Control existence is static.** A control proves that a cited assertion
  EXISTS in a gate-wired test file and is CALLED from that module's `main()`;
  it does not prove the assertion passed. Pass status is the gate's exit code.
- **A bold `NONE` is not 'fine'.** It means no control in this repository
  can move that number today. The reasons are all listed in the register below.
- Companion rules (those carrying `siem.companion_of`, `score_weight: 0`) COUNT as
  separate rules: they have their own rule ids and fire on their own. They are
  marked `†` in the per-technique table so a reader can tell them from standalone
  rules. The owner decided this; the alternative (folding them into their
  sibling) would hide rules that really do fire.
- Timestamps, wall-clock values and Windows paths are deliberately absent: the
  renderer refuses to read the volatile keys `date`, `elapsed_seconds`, `assembly_median_ms`, `assembly_samples_ms`, `incident_reconstruction_time_ms`.
